Slide 02 • Problem Statement

The Challenge of Fragmented Digital Footprints

🧩 Fragmented Artifacts
Users constantly switch between browsers (Chrome, Edge) and local software (VS Code, Word, Downloads). Every program logs timestamped actions in isolated, proprietary formats with differing epoch systems.
🔍 The Investigation Gap
During malware incidents, data leaks, or student evaluations, examiners need to know: What was searched? What was downloaded? What executable was launched next? Answering this requires correlation.
⚖️ Enterprise Software Bloat
Commercial tools like FTK Imager or EnCase are heavyweight, expensive, and complex. There was no lightweight, zero-setup Python tool designed for rapid timeline reconstruction.

Slide 05 • Key Innovation 1

Browser Forensics & Safe Database Cloning

🛡️ Safe Shadow DB Cloning
Active browsers hold exclusive OS locks on the History SQLite file. Direct access raises sqlite3.OperationalError: database is locked.
temp_file = tempfile.NamedTemporaryFile(delete=False) shutil.copy2(history_path, temp_file.name) conn = sqlite3.connect(temp_file.name)
This guarantees 100% crash-free extraction while browsers remain open!
⏰ WebKit Epoch Conversion & Queries
Chromium counts microseconds since January 1, 1601 UTC:
def chrome_to_dt(ts): return datetime(1601, 1, 1) + timedelta(microseconds=ts)
Automatically extracts keywords from query parameters (?q=, search_query=) across Google, Bing, and YouTube.
Slide 06 • Key Innovation 2

OS Artifacts & Chronological Correlation

📂 Operating System Artifacts
• Windows Recent Items: Parses shortcut (.lnk) files in %APPDATA%\Microsoft\Windows\Recent with modified timestamps.

• Incognito & Private Forensics: Captures active kernel sockets (ports 80/443), performs Reverse DNS, queries OS DNS cache, and scans persistent downloads.

• Extension Classifier: Intelligent tagging into Documents, Source Code, Executables, and Media.
⚡ Chronological Correlation Engine
Normalizes all disparate artifacts into unified Python dictionaries:
{ "timestamp": "2026-11-21 22:22:31", "source": "Microsoft Edge", "category": "Web Visit", "title": "College Portal Login", "details": "https://exam.college.edu/login", "extra": "Visits: 2 | Typed: 1" }

Slide 08 • Visual Analytics

Visual Analytics & Forensics Metrics

📊 Hourly Distribution
24-hour histogram (00:00 to 23:00) showing user activity patterns. Instantly flags suspicious off-hours operations (e.g. 2 AM - 4 AM).
🥧 Category Breakdown
Pie chart visualizing the distribution of Web Visits vs. Web Searches vs. File Downloads vs. Application Executions.
📈 Top Web Domains
Horizontal bar chart ranking the most visited internet domains, highlighting frequent external connections and potential exfiltration sites.
