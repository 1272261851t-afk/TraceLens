1. Ingestion Sources & Data Models
Chromium SQLite History (Chrome & Edge)
Table: urls (url, title, visit_count, typed_count, last_visit_time)
Table: downloads (target_path, tab_url, total_bytes, start_time)
Windows Recent File Artifacts
Path: %APPDATA%\Microsoft\Windows\Recent
Binary .lnk shortcuts with last-modified timestamps and target file paths.
User Downloads Storage Scanner
Path: ~/Downloads
Live physical file indexing, byte sizing, and extension identification.
2. Lock Bypassing Algorithm (Shadow Copy)
When web browsers are actively running, Windows places exclusive write locks on SQLite databases.
temp_file = tempfile.NamedTemporaryFile( delete=False, suffix=".sqlite" ) shutil.copy2(history_file_path, temp_file.name) conn = sqlite3.connect(temp_file.name) # Query safely, then clean up temp file!
Guarantees: 100% non-blocking data access with zero database lock crashes.
3. Epoch Conversion & Query Decoding
Chromium WebKit Timestamp Formula:
Counts microseconds elapsed since January 1, 1601 UTC.
def chrome_time_to_datetime(ts): epoch_start = datetime(1601, 1, 1) return epoch_start + timedelta(microseconds=ts)
URL Query String Extractor:

4. Timeline Correlation Engine
Standardizes all disparate inputs into a unified dictionary structure:
{ "timestamp": "2026-11-21 22:22:31", "dt": datetime_obj, "source": "Microsoft Edge", "category": "Web Visit", "title": "College Portal Login", "details": "https://exam.college.edu/login", "domain": "college.edu", "extra": "Visits: 2 | Typed: 1" }
Chronological in-memory sorting: O(N log N) via Timsort.
